# Шаблон issue для находок Lighthouse

Одна issue — одна страница. В теле обязателен отпечаток страницы: по нему прогон находит
существующую issue и не создаёт дубль.

```markdown
<!-- lighthouse: {{path}} -->

## Что не проходит

| Метрика | Бюджет | Замер |
| --- | --- | --- |
{{rows}}

## Замер

- Дата: {{date}} (Europe/Moscow)
- Коммит: `{{sha}}`
- Прогон: {{run_url}}
- Профиль: mobile, 3 прогона, медиана

Бюджеты — в `.lighthouserc.json`. Сырые отчёты лежат в артефакте прогона 30 дней.
```

## Правила

- Отпечаток `<!-- lighthouse: <path> -->` переносится дословно; строка не меняется между прогонами.
- Строки таблицы копируются из `.lighthouseci/findings.md` без правок.
- Метка — `lighthouse`.
- Заголовок — `[lighthouse] <path>`.
- Открытая issue с тем же отпечатком: тело перезаписывается, комментарий не добавляется.
- Закрытая issue с тем же отпечатком: `reopen`, затем перезапись тела.
